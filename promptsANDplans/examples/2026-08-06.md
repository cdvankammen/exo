## E11: Qwen3.5-2B Blackwell fix (Linux box, CUDA 12.8)

```bash
# 1. Install CUDA 12.8 runtime libs (first with Blackwell sm_120 JIT support)
curl -fsSL https://developer.download.nvidia.com/compute/cuda/repos/ubuntu2404/x86_64/cuda-keyring_1.1-1_all.deb -o /tmp/cuda-keyring.deb
dpkg -i /tmp/cuda-keyring.deb
apt-get update
apt-get install -y cuda-nvrtc-12-8 cuda-nvvm-12-8 cuda-cudart-dev-12-8

# 2. Symlink the 12.8 libs over system ones
# (find them in /usr/local/cuda-12.8/targets/x86_64-linux/lib/ or NVIDIA repo paths)
ln -sf <path-to-12.8>/libnvrtc.so.12 /usr/lib/x86_64-linux-gnu/libnvrtc.so.12
ln -sf <path-to-12.8>/libnvvm.so.4 /usr/lib/x86_64-linux-gnu/libnvvm.so.4

# 3. RE-FIX driver libs (apt clobbered 595.84 over our 595.58.03)
# re-run linux-deployment-log Phase 6 steps (copy .run libs + symlink)

# 4. Verify JIT works
CUDA_HOME=/usr/local/cuda CUDA_PATH=/usr/local/cuda .venv/bin/python -c "
import mlx.core as mx
@mx.compile
def f(x): return x * 2
print(f(mx.array([1,2,3])))"

# 5. Place + chat Qwen3.5-2B single-node
curl -X POST http://localhost:52415/place_instance -H "Content-Type: application/json" \
  -d '{"model_id":"mlx-community/Qwen3.5-2B-MLX-8bit","sharding":"Pipeline","instance_meta":"MlxRing","min_nodes":1,"force_override":false}'
# → "warmed up by generating 50 tokens", chat ~17.6 tok/s
```
